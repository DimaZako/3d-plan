# Сповіщення бота @fishka_3d_bot

Коли Telegram згорнутий, Mini App заморожується і не може сама показати сповіщення. Тому сповіщення надсилає невеликий сервер (`worker.js`):

1. Mini App після кожного збереження, перезапуску чи редагування плану надсилає на сервер розклад.
2. Сервер щохвилини перевіряє розклад і пише в чат бота:
   - `⏰ Дет2 · цикл №3: залишилось 5 хв, кінець о 13:54`;
   - `✅ Дет2 · цикл №3 завершено о 13:54. Перезапуск: 15 хв`.
3. Telegram показує ці повідомлення звичайною плашкою, навіть якщо застосунок згорнутий чи екран заблокований.

Сервер працює на Cloudflare Workers. Безкоштовного плану вистачає з великим запасом.

## Розгортання (приблизно 10 хвилин)

1. Увійдіть або зареєструйтеся на https://dash.cloudflare.com, вибравши безкоштовний план.
2. **База даних.** Storage & Databases → **D1 SQL Database** → **Create**. Назва `fishka3d` → **Create**.
3. **Worker.** Compute → **Workers & Pages** → **Create** → *Start with Hello World* → назва `fishka-3d-notify` → **Deploy**.
4. **Код.** Натисніть **Edit code**, видаліть усе й вставте вміст файлу [`worker.js`](https://raw.githubusercontent.com/DimaZako/3d-plan/main/notify/worker.js) → **Deploy**.
5. **Прив'язка бази.** Worker → **Settings** → **Bindings** → **Add binding** → *D1 database*. Variable name: `DB`, база: `fishka3d` → **Add binding**.
6. **Токен бота.** Worker → **Settings** → **Variables and Secrets** → **Add**. Type: **Secret**, Name: `BOT_TOKEN`, Value: токен із @BotFather (`/mybots` → @fishka_3d_bot → *API Token*) → **Deploy**.
7. **Розклад перевірки.** Worker → **Settings** → **Trigger Events** → **Add** → **Cron Triggers** → *Every minute* (`* * * * *`) → **Add**.
8. Відкрийте адресу воркера (`https://fishka-3d-notify.<ваш-піддомен>.workers.dev`). Має з'явитися напис «3D План: сервер сповіщень працює».

Токен вводьте лише в Cloudflare як Secret і нікому його не пересилайте.

## Підключення до Mini App

Адресу воркера треба прописати в `index.html` як `NOTIFY_URL`. Після цього в плані з'явиться рядок «Сповіщення в чат бота…» з кнопкою «Вимкнути». Цей вибір спільний для всіх ваших пристроїв.

## Як це працює всередині

- `POST /sync` перевіряє підпис Telegram (`initData`) токеном бота. Тому записати розклад може лише справжній користувач бота, і лише для себе.
- Новий розклад замінює всі ще не надіслані події. Уже надіслані не повторюються.
- Cron щохвилини надсилає події, час яких настав. Події, пропущені більш ніж на 15 хв, не надсилаються. Старі записи видаляються через 2 доби.
