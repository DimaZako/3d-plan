# 3D План — Telegram Mini App

Увесь застосунок — це один файл `index.html`. Окремий сервер для бота не потрібен. Telegram відкриває сторінку за кнопкою меню в чаті з ботом, а історія планів зберігається в хмарі Telegram (CloudStorage), окремо для кожного користувача й однаково на всіх його пристроях.

## 1. Розмістити `index.html` за HTTPS-адресою

Telegram відкриває Mini App лише з адреси `https://`.

**Варіант А: Netlify Drop (найшвидше, без git)**
1. Відкрийте https://app.netlify.com/drop і увійдіть (безкоштовно).
2. Перетягніть у вікно папку `3d-plan-telegram` з файлом `index.html`.
3. Скопіюйте адресу, яку видасть Netlify, наприклад `https://назва.netlify.app`.

**Варіант Б: GitHub Pages**
1. Створіть публічний репозиторій і завантажте в нього `index.html`.
2. Settings → Pages → Source: *Deploy from a branch* → гілка `main`, папка `/ (root)` → Save.
3. Через хвилину адреса буде такою: `https://<логін>.github.io/<репозиторій>/`.

Щоб оновити застосунок, замініть `index.html` тим самим способом. Бот підхопить нову версію автоматично.

## 2. Підключити до бота в @BotFather

**Якщо бота ще немає:** `/newbot` → назва → username (має закінчуватися на `bot`).

**Кнопка біля поля вводу** (як «Калькулятор» у старому боті):
`/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button** → надішліть адресу з кроку 1 → надішліть назву кнопки, наприклад `Калькулятор`.

**Необов'язково, головний Mini App** (кнопка «Відкрити» в профілі бота і посилання `t.me/<бот>?startapp`):
`/mybots` → ваш бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → та сама адреса.

Якщо `@easy_calculat_bot` ваш, досить замінити в ньому адресу кнопки меню на нову.

## 3. Перевірка

1. Відкрийте чат з ботом на телефоні й натисніть кнопку меню.
2. Заповніть поля й натисніть велику нижню кнопку **«Розрахувати»**.
3. Після кінця циклу внизу з'явиться **«Завершити перезапуск»**. Якщо норму перевищено, кнопка стане червоною й покаже, на скільки.

Якщо кнопка меню не оновилася, закрийте чат з ботом і відкрийте його знову: Telegram кешує меню.

## Що варто знати

- **Сигнали.** За 5 хв до кінця друку лунає двотональний сигнал, телефон вібрує, і з'являється підказка з часом завершення. Коли цикл закінчився, лунають три короткі сигнали. Сигнал увімкнений за замовчуванням, а вимкнути його можна кнопкою «Сигнал» у банері. Браузер дозволяє звук лише після першого дотику до екрана, тож доти кнопка показує «Увімкнути звук».
- Сигнали працюють, поки застосунок відкритий. Коли відкрито план, що виконується, і сигнал увімкнений, застосунок просить телефон не гасити екран, якщо телефон таке підтримує.
- Поки застосунок закритий, нагадувань не буде: Telegram не дозволяє Mini App надсилати сповіщення сам по собі. Для повідомлень на кшталт «Цикл №3 завершено» потрібен невеликий серверний бот.
- Хмара Telegram вміщує близько 1000 записів на користувача. Застосунок зберігає 300 останніх планів, а старіші видаляє сам.
- Якщо відкрити `index.html` просто в браузері, поза Telegram, він теж працює. Історія тоді зберігається в цьому браузері, і там доступні збереження TXT, зображення й файл для календаря.
